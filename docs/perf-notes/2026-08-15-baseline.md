# Performance Baseline — 2026-08-15

First recorded baseline. Machine: Apple Silicon laptop (darwin arm64),
release profile (`lto = "fat"`, `codegen-units = 1`), mimalloc.
Reproduce: `cargo bench` + `cargo run --release -p rig -- <mode>`.

Decision record: the scanner's `string_token` was memchr-accelerated after
this baseline's first draft showed it losing to serde_json on large bodies
(25.7 µs → 1.36 µs at 64 KB). A SIMD JSON library remains unnecessary for
the probe path at these numbers.

## End-to-end rig (in-process mock, open loop, warm pools)

`rig overhead --rps 1000 --secs 8`:

| Measure | p50 | p99 | p99.9 |
|---|---|---|---|
| Gateway-internal overhead (`x-rapid-overhead-us`) | **6 µs** | **24 µs** | 74 µs |
| Round-trip delta vs direct | 158 µs | 383 µs | — |

The round-trip delta includes one extra localhost TCP hop plus
client/mock/gateway contention on shared cores; the header value is the
gateway's own added time (request receipt → upstream dispatch, plus
response forwarding, minus upstream wait). Budgets (<10 µs p50
passthrough, <100 µs p99) hold at 1,000 RPS.

Found and fixed while building the rig: `x-rapid-overhead-us` had
regressed to reporting total duration including upstream time; it now
subtracts the serving attempt's upstream wait.

## Soak

`rig soak --secs 40 --rps 300`: RSS flat (9.7 MB → 9.5 MB, 0% growth),
p99 round-trip stable (~570 µs) across the run. The first soak run
caught the mock provider's unbounded request recorder (now capped at
1,000 entries) — the gateway itself was already flat.

## Streaming

`rig stream`: TTFB p50 delta ≈ 190 µs including the extra hop; dominated
by the mock's paced first frame (~100 ms), so the delta, not the
absolute, is the signal.
